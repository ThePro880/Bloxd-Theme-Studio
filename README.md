Bloxd.io Theme Studio (v3.1)



An all-in-one Chrome extension for Bloxd.io featuring an FPS Booster, custom visual themes, local PC Image/GIF backgrounds, PvP HUD overlays, draggable client widgets, 1-click profiles, an Arcade \& Shop with minigames, Favorite Lobbies, and a floating OST / MP3 / YouTube music player.



Features



\- FPS Booster (New in v3.1):

&nbsp; - 3D WebGL Resolution Scaling: choose between 100% (Native), 85% (Balanced), 75% (High FPS), or 60% (Potato Mode) to lower GPU load.

&nbsp; - High-Performance WebGL Context: disables antialiasing and requests high-performance GPU acceleration on page load.

&nbsp; - Live UI Optimizations: remove CSS backdrop blur and shadows, disable menu animations, and hide ad containers.

&nbsp; - 1-Click Presets (Off, Balanced, Ultra) and a draggable live FPS, frame-time (ms), and Min/Max FPS counter.

\- Visuals, Themes \& Backgrounds:

&nbsp; - Instant presets (Christmas, Halloween, Summer) plus bonus presets (Midnight Neon, Sakura Blossom, Cyberpunk 2077, AMOLED Black, Blocky Grass).

&nbsp; - Custom Theme Creator, inline Theme Editor, Random Theme Generator (Dice), and Import / Export theme codes.

&nbsp; - Upload local Images or animated GIFs from your PC (stored in IndexedDB) or use URL and 2-color gradient backgrounds with a darkness slider.

&nbsp; - Glassmorphism (translucent blurred sidebar and panels), animated Rainbow RGB borders, custom fonts (Pixel, Futuristic, Rounded), custom SVG and 24x24 PNG cursors, and animated particles with shapes (Circles, Pixel Blocks, Stars, Rain Drops).

\- PvP HUD \& Client Widgets:

&nbsp; - Custom Crosshair overlay (Classic Cross, Cross + Dot, Dot, Circle + Dot, or uploaded PNG) with color, black outline, size, thickness, gap, opacity, in-game only toggle, and dynamic click pulse.

&nbsp; - Draggable WASD Keystrokes with LMB / RMB CPS counter and Space bar.

&nbsp; - Live FPS counter and Session Clock / Parkour Speedrun Stopwatch.

&nbsp; - Extras \& 1-Click Profiles (PvP, Chill, Parkour, plus Save / Load My Setup): Client Watermark, Live Ping Meter, Real-Time Clock (12h/24h), Max CPS Tracker, Coordinates Notepad (X/Y/Z), Menu Cursor Trail, Click Ripples, Ambient Edge Glow, Custom Browser Tab Title, Menu UI Click Sounds, and Full JSON Backup Export / Import.

\- Arcade \& Shop (in More Settings):

&nbsp; - 5 built-in minigames (Aim Trainer, Mining Rush, Block Dodge, Parkour Jump, Memory Blocks) awarding +3 Coins per win.

&nbsp; - Unlockable shop rewards: pixel weapon cursors, RGB / Fire / Diamond cursor trails, Pixel Crown watermark, Shiny Gold Border, 8-Bit and PvP Hitmarker sound packs, and exclusive themes (Matrix Hacker, Gold Royale, Void Galaxy).

\- Floating OST / MP3 / YouTube Music Player:

&nbsp; - Draggable mini player with built-in Bloxd OST playlists, local PC MP3 / OGG / WAV / M4A uploads, and YouTube Music search \& playlist with toggleable mini video preview.

&nbsp; - Shuffle, Repeat, Live Beat Visualizer, Playback Speed (0.05x to 2.00x), Bass Boost, and Nightcore / Slowed audio effects.

\- Favorite Lobbies:

&nbsp; - Save Worlds, Survival, Peaceful, Creative, Bedwars, Skywars, Greenville, and Custom Game lobby names or URLs for 1-click copy or launch.



Hotkeys



\- Alt + F: Open / Close FPS Booster Panel

\- Alt + Shift + F: Show / Hide FPS Booster Counter

\- Alt + T: Start / Pause Parkour Speedrun Stopwatch

\- Alt + R: Reset Parkour Speedrun Stopwatch

\- Esc: Return to Bloxd.io from More Settings or close open modals



Installation (Chrome / Edge / Brave)



1\. Download bloxd-theme-studio-v3.1.zip from the Releases section (or click Code -> Download ZIP).

2\. Extract the .zip file to a folder on your PC.

3\. Open chrome://extensions in your browser.

4\. Enable Developer mode (top-right corner).

5\. Click Load unpacked and select the extracted folder containing manifest.json.

6\. Open https://bloxd.io/ and refresh the page (Ctrl + F5).
